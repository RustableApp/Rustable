# Redis command metadata

commands.json is adapted from Redis 7.2.6 src/commands/*.json (https://github.com/redis/redis/tree/7.2.6/src/commands), BSD-3-Clause; see LICENSE. It retains command summaries, versions, groups and argument grammar, with container names normalized. It is bundled offline and does not assert server availability. Module additions are maintained separately by Rustable.
