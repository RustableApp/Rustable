# Rustable v0.4.32

- Connect an AI agent to your live SQL workspace through MCP on macOS and Linux. Find setup details in the AI menu or connection manager, then enable AI control for each connection you want to share.
- Watch agents read and edit your actual SQL tabs, stream changes, run queries and leave results you can continue working with. The Matrix activity bar shows AI work; Stop or Escape pauses access and requests query cancellation. Existing database permissions, Safe mode and human confirmations still apply.
- Copy a query and its results together using Share Results or Copy Query + Rows. Choose plain text, Markdown or JSON, with the original executed query preserved even after you edit the SQL tab.
- Export table definitions and data together as SQL, and customize CSV output.
- Preserve indentation and pair parentheses while editing SQL, with improved spacing above results.
- Replace the blocky loading indicator with flowing cyan and violet aurora ribbons. AI activity keeps its distinct green Matrix animation.

MCP requires Rustable to stay open. Copy its connection configuration again after restarting. Windows and browser MCP support, Redis agent control, and built-in AI chat are not included in this release.
