# Rustable v0.4.24

- Align the query editor’s line and column counter with the SQL text, immediately after the line-number gutter.
- Keep multiple query results in a stable, single-row tab strip with horizontal scrolling and automatic reveal of the selected result.
- Match result tabs to the workspace tabs, with consistent rounded corners, colors, typography and selected borders in both themes.
- Keep large result batches responsive by rendering only visible result tabs.

The website demo is built from the same release tag.
