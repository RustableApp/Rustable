# Rustable v0.4.33

- Enable AI directly from the MCP setup dialog. The compact footer has matching Cancel and Enable AI buttons; enabling closes the dialog and shares the current SQL workspace in one click.
- See open and failed transactions clearly in the connection bar, with COMMIT / ROLLBACK guidance. Transaction status remains visible during queries and AI activity without adding another toolbar row.
- Confirm before removing a saved connection and its saved passwords. Cancel preserves the connection and unsaved edits; database contents are unaffected.
- Find the AI workspace workflow and setup guide in the README.

MCP remains available on macOS and Linux for explicitly enabled SQL workspaces. Database permissions, Safe mode and human confirmations still apply.
