# Rustable v0.4.28

- Double-click empty space below or beside table rows to add a new row and start editing it.
- Use Cmd+Z while editing a cell to undo typing first, then continue undoing earlier staged changes. Redo remains available.
- Closing a table, database workspace, or window—or quitting with pending edits—now offers Cancel and Discard. Closing a table discards only that table’s edits. SQL drafts are retained, and running work or open transactions still prevent closing.
- Keep highlighted text readable while editing: the active cell returns to its normal background while the rest of the selected row stays blue.

The website demo is built from the same release tag.
