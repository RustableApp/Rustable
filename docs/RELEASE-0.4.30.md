# Rustable v0.4.30

- Select a row by clicking anywhere to its right. Click below all rows to clear the selection, and use Cmd+A in the main table to select all loaded cells.
- Show new rows in green, while changes to existing values stay orange.
- Navigate pending rows with arrow keys, including moving between existing and new rows. The selected cell scrolls into view; Enter or a double-click opens it for editing.
- Keep pending-cell text unselectable until you enter edit mode.
- Move the cell selector to the affected cell when undoing or redoing staged edits, including changes to pending rows.

The website demo is built from the same release tag.
