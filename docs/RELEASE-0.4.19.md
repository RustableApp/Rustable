# Rustable v0.4.19

- A much richer Redis workspace: Browse, Search, Workbench, Analyze and Pub/Sub, with list/tree key navigation, type filters and paged value inspectors.
- Highlighted command editing with Command/Ctrl+Enter, saved commands and a Workbench history sidebar. JSON documents edit inline, copy actions confirm success, and key actions sit beside the key name.
- Redis Search index browsing, queries, aggregations and profiles; on-demand memory analysis with top namespaces and top 15 sampled keys; live Pub/Sub and command profiling.
- Reviewed key and collection changes, expiry controls, bulk operations and Redis archive import/export, with read-only and conflict safeguards.
- Cluster and Sentinel connections, plus time-series and Redis 8.4 vector-set browsing, element details and similarity results.

Redis server connections require the desktop app. Module features require compatible servers and permissions; the browser Redis demo is an in-memory subset. History is session-only. Analysis samples loaded keys rather than the entire database.

The website demo is built from the same release tag.
