# Rustable v0.4.29

- Continue Cmd+Z from cell typing into earlier staged cell edits, with the caret returning to the start and focus following the affected cell. Redo preserves fresh typing.
- Reopen and edit orange staged cells before committing.
- Refresh or change views freely when a cell editor is unchanged, including the right-hand inspector.
- When edits are pending, choose Cancel or Discard before refreshing or navigating. Cancel keeps your edits; Discard continues the requested action. Table-specific actions preserve other tables’ changes.
- Use a compact discard warning with rounded buttons and a short save hint.

The website demo is built from the same release tag.
